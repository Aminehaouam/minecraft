# TerraCraft 2D — لعبة روبلوكس تمزج تيراريا وماين كرافت

لعبة ساندبوكس ثنائية الأبعاد كاملة لروبلوكس: عالم مولّد إجرائياً بأكثر من
مليون بلاطة، تعدين وبناء، تصنيع متدرّج، وحوش وزعيم، دورة ليل ونهار، إضاءة
ديناميكية، لعب جماعي، وحفظ دائم.

كل الرسوميات مبنية برمجياً من أشكال ملوّنة — **لا تحتاج رفع أي صورة أو صوت**.

---

## التشغيل السريع

```bash
# 1) ثبّت الأدوات (rokit أو aftman)
rokit install

# 2) شغّل خادم Rojo
rojo serve

# 3) في Roblox Studio: أنشئ مكاناً فارغاً، ثبّت إضافة Rojo، واضغط Connect
```

بديل بلا خادم مباشر — بناء ملف مكان جاهز:

```bash
rojo build -o TerraCraft.rbxlx
# ثم افتح TerraCraft.rbxlx في Studio واضغط Play
```

> **مهم للحفظ**: فعّل `Studio → Game Settings → Security → Enable Studio Access to API Services`
> ليعمل DataStore. بدونها تعمل اللعبة طبيعياً لكن الحفظ في الذاكرة فقط.

### تشغيل الاختبارات

```bash
# نزّل مُفسِّر Luau من luau-lang/luau ثم:
python3 tests/run.py /path/to/luau
```

## التحكم

| المفتاح | الوظيفة |
|---|---|
| `A` / `D` أو الأسهم | الحركة |
| `المسافة` / `W` | القفز (ارتفاع متغيّر بالضغط المستمر) |
| `S` | النزول عبر المنصات / التسلّق للأسفل |
| **الزر الأيسر** | الفعل الأساسي: يضع البلاطة إن كنت تحمل واحدة، وإلا يُعدّن، وإلا يهاجم |
| **الزر الأيمن** | هجوم دائم / استعمال الجرعات والأغراض الخاصة |
| `1` … `0` | اختيار خانة من شريط الأدوات |
| عجلة الفأرة | تبديل الخانة |
| `E` | المخزون + التصنيع |
| `Q` | رمي العنصر (`Ctrl+Q` لرمي الكومة) |
| `F` | وضع الجدران الخلفية (مع المطرقة للهدم) |
| `R` | متجر التاجر (قرب نقطة الظهور) |
| `Esc` | إغلاق النوافذ |

**في المخزون**: نقرة لاختيار خانة ثم نقرة أخرى للتبديل. نقرة يمنى تُجهّز الدرع
أو ترمي عنصراً واحداً. نقرة على وصفة تصنع واحدة، ونقرة يمنى تصنع عشراً.

**على الهاتف**: أزرار حركة وقفز وتعدين وهجوم تظهر تلقائياً.

## ماذا في اللعبة؟

### العالم
- **2048×512 بلاطة** مولّدة إجرائياً من بذرة ثابتة للخادم (العالم نفسه للجميع).
- **خمس مناطق حيوية**: غابة، سهول، صحراء، أدغال، أرض ثلجية — لكلٍّ تضاريسه ونباتاته.
- **أربع طبقات عمق**: السطح ← تحت الأرض ← الأعماق ← الجحيم (بحيرات حمم وحجر جهنمي).
- كهوف وأنفاق، بحيرات جوفية، أشجار، صبّار، فطر متوهج، خيوط عنكبوت، بلّور.
- **جدران خلفية** تُبنى وتُهدم بالمطرقة (تمنع ظهور الوحوش وتحجب الضوء جزئياً).
- **سوائل تتدفّق**: الماء يهبط وينساب إلى المنافذ، والماء + الحمم = سبج.
- البلاطات غير المسنودة (مشعل، زهرة، سلّم) تسقط عند إزالة سندها.
- قطع الجذع يُسقط الشجرة كاملة، والشتلات تنمو مع الوقت.

### التقدّم
- **7 مستويات معاول**: خشبي ← حجري ← نحاسي ← حديدي ← ذهبي ← ألماسي ← ميثريل.
  كل خام يحتاج قوة معول معيّنة، فالتقدّم مقفول بترتيب منطقي.
- **9 سيوف** و**3 أقواس** و**عصوان سحريتان** (تستهلكان المانا).
- **5 أطقم دروع** مع مكافأة طقم كامل (+6 دفاع).
- **4 محطات تصنيع**: طاولة عمل، فرن، سندان، طاولة خيمياء.
- **بلّورات الحياة والمانا** ترفع الحد الأقصى (حتى 300 حياة و200 مانا).
- **جرعات**: حياة، مانا، سرعة، جلد حديدي، توهج — مع إجهاد جرعات يمنع الإدمان.

### القتال والبقاء
- حياة، مانا، جوع، دفاع، ضرر سقوط، غرق، حروق الحمم.
- **11 نوع وحش** بأنماط ذكاء مختلفة: هلاميات قافزة، زومبي، عيون شيطانية طائرة،
  هياكل ترمي العظام، خفافيش، عناكب متسلّقة، دبابير، غيلان حجرية، عفاريت حمم،
  زواحف ظل.
- الوحوش تظهر حسب الطبقة والمنطقة والوقت، وتحترق في ضوء النهار.
- **قمر الدم**: ليلة عنيفة عشوائية بعد اليوم الثالث (وحوش أكثر وأقوى).
- **زعيم**: «عين الأعماق» يُستدعى بطوطم العين ليلاً — ثلاث مراحل، اندفاع، وابل
  مقذوفات، واستدعاء أتباع. حياته تتوسّع مع عدد اللاعبين.
- أرقام ضرر طائرة، ضربات حرجة، ارتداد، اهتزاز شاشة.

### اللعب الجماعي
- عالم مشترك واحد: تعديلات أي لاعب تظهر للجميع فوراً.
- ترى اللاعبين الآخرين بأسمائهم ودروعهم وأسلحتهم.
- مخزون وإحصاءات كل لاعب محفوظة في DataStore.

## بنية المشروع

```
roblox/
├─ default.project.json      إعداد Rojo
├─ src/
│  ├─ shared/                منطق نقي مشترك بين الخادم والعميل
│  │  ├─ Config.luau         كل الأرقام القابلة للضبط
│  │  ├─ Blocks / Items / Recipes / Mobs / Buffs   سجلات المحتوى
│  │  ├─ Noise / WorldGen    التوليد الإجرائي الحتمي
│  │  ├─ Chunk / World       تخزين العالم والتعديلات
│  │  ├─ Physics / Mining    فيزياء AABB وصيغة زمن الكسر
│  │  └─ Inventory / Net     منطق المخزون وقنوات الشبكة
│  ├─ server/                مرجع الحقيقة: عالم، لاعبون، كيانات، تصنيع، حفظ
│  └─ client/                الرسم، الإدخال، التنبؤ، الواجهة
│     ├─ Renderer / Lighting / Sprites / Fx / Sfx
│     └─ UI/ (Theme, Hud, Panels)
├─ tests/                    اختبارات تعمل خارج روبلوكس بمُفسِّر Luau
└─ docs/ARCHITECTURE.md      شرح القرارات التقنية
```

**قاعدة الطبقات**: `shared` لا يعرف شيئاً عن الخادم أو العميل، والعميل لا يملك
أي حقيقة — الخادم يملكها كلها. هذا ما يجعل الاختبارات ممكنة ومنع الغش واقعياً.

## الضبط والتوسيع

كل الأرقام في `src/shared/Config.luau`: حجم العالم، الجاذبية، سرعة المشي، طول
اليوم، حدود الظهور، معدلات الشبكة، مدى التعدين… غيّر من هناك فقط.

**إضافة بلاطة جديدة**: أضف معرّفاً في `Blocks.ID` ثم `def({...})`، وعنصراً في
`Items.luau` بـ `blockItem(...)`. صارت قابلة للبناء والكسر والإسقاط تلقائياً.

**إضافة وحش**: `def({...})` واحد في `Mobs.luau` — نظام الظهور والذكاء والرسم
يلتقطه تلقائياً حسب `ai` و`layer` و`biomes`.

**إضافة وصفة**: سطر `R("out", n, {...}, "station")` في `Recipes.luau`. الاختبارات
تتحقق تلقائياً أن كل عنصر جديد قابل للوصول من المواد الأولية.

## حدود معروفة (بصراحة)

- **الصناديق**: البلاطة موجودة وتُبنى وتُكسر، لكن واجهة تخزين الصناديق لم تُنفَّذ
  بعد (`Net.Container` محجوزة لها).
- **الفرن** يعمل كمحطة تصنيع تستهلك الفحم كمكوّن، لا كفرن بحالة وزمن صهر.
- **تدفّق السوائل** محافظ على الكتلة: الماء يهبط وينساب إلى المنافذ، لكنه لا
  «يتسطّح» على أرض مستوية كما في تيراريا (قرار مقصود لتجنّب تكاثر الماء وكلفة المحاكاة).
- **الأصوات** من مكتبة روبلوكس المدمجة؛ استبدل المعرّفات في `Sfx.luau` بأصوات
  أفضل إن أردت.
- لا توجد خريطة مصغّرة؛ يظهر بدلاً منها مؤشر الطبقة والمنطقة والعمق.
